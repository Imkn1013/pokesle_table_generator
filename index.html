【不具合】 　食材とくいA食材数について、食材構成の関係であえてレベルを下げたほうがA食材取得数が増える場合は, lv29やlv59に落としているのですが、サブスキルが解放されたまま計算されています。
食材構成と設定レベルにより、
ABXならlv50~74→1枠分,lv75~99→2枠分,lv100~→3枠分,
AAXならlv75~99→1枠分,lv100~→2枠分　だけ
サブスキルの枠が本来より余計に増えていることに注意してください。
改善するためにサブスキルの順序を区別すると表が煩雑になることを考え、ひとまず現状を維持する方針です。
　
出現確率について 　サブスキルの抽選は、メダルによる金色確定枠を金色から等確率で抽選した後、未出現のものから1つあたり(白:12.5、青:6、金:2)の重みに基づいた確率で計算しています。実際の抽選方法と異なる可能性がありますので注意してください。
　
おてつだいボーナスの扱いについて おてつだい時間のサブスキル補正は、
　max( 0.65 , 1 - { (スピSの数)*0.07 + (スピMの数)*0.14 + (チーム全体のおてボの数)*0.05 } )
倍で、状況によって1倍から全員に1.076倍程度(実質1匹に約1.385倍)まで幅があり、他のポケモンが影響するため厳密な強さは計算できませんが、編成ポケモン全員が同様におてボを持っているとして計算(-0.25)しています。ただし、実際そのような状況は限定的で、多くの場合では他のポケモンへの効果量を擬似的に計算していると捉え、キャップは撤廃しました。本来キャップのかかるM+おてボ*5、S+M+おてボ*3以上という状況では過大評価になりますので注意してください。他の編成ポケモンが強ければ相対的におてボが強く、他の編成ポケモンが弱ければ相対的に弱くなることにも注意してください。
